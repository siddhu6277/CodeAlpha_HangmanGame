## Project 2: Hangman Game

A modern and interactive **Hangman Game** developed using **Python and Streamlit** as part of the **CodeAlpha Python Programming Internship**.

The player must guess a randomly selected programming-related word one letter at a time before running out of lives.

## 📌 Project Overview

This project started as a command-line Python Hangman game and was upgraded into an interactive web application using **Streamlit**.

The game randomly selects a hidden word and allows the player to guess letters using an interactive on-screen keyboard. Correct guesses reveal letters in the word, while incorrect guesses reduce the player's remaining lives.

## ▶️ Run Locally

Start the Streamlit application using:

```bash

```

Streamlit will start a local development server and open the application in your browser.

## 🎮 How to Play

1. Select a difficulty level.
2. A random programming-related word will be chosen.
3. Click letters from the on-screen keyboard to make a guess.
4. Correct letters will appear in the hidden word.
5. Incorrect guesses will reduce your remaining lives.
6. Use the hint if you need some help.
7. Guess the complete word before your lives reach zero.
8. Win games to increase your score and winning streak.
9. Click **Play Again** to start another round.
