# CodeAlpha Python Internship

## Project 2: Hangman Game

### Description
A simple Python Hangman game where the player guesses a hidden word one letter at a time.

### Features
- Random word selection
- Letter-by-letter guessing
- 6 attempts
- Win/Lose conditions
- Input validation

### Technologies Used
- Python 3

### How to Run

```bash
python hangman.py
```
